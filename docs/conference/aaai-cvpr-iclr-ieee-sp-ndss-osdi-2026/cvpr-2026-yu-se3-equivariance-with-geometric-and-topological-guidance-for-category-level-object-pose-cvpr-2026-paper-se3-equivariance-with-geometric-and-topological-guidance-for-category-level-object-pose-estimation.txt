## Abstract 

Object pose estimation is a key task for embodied robots, enabling them to interact with objects effectively. Category-level object pose estimation provides a way for robots to estimate the pose of unknown objects. However, estimat-ing object pose from point clouds alone remains challeng-ing. In this paper, we introduce SEGPose, a novel category-level object pose estimation method based on point clouds. Unlike previous methods, SEGPose leverages geometric, topological information, and SE(3)-equivariance, enhanc-ing the network’s accuracy in pose prediction. To utilize ge-ometric and topological features, we propose a constraint-based feature extraction and 3D reconstruction method, en-abling effective object shape reconstruction. We also de-sign an SE(3)-equivariance feature prediction network to handle pose transformations consistently across viewpoints, improving pose accuracy. Experimental results on bench-mark datasets show that SEGPose outperforms all cur-rent category-level pose estimation methods based on point clouds. Additionally, we apply the SEGPose to the robotic grasping tasks in real-world scenarios, and the results in-dicate that SEGPose exhibits excellent generalization capa-bilities.

To overcome the reliance on object models in instance-level pose estimation, category-level methods [3, 5, 20, 32, 35] have been proposed. The predicted pose must adapt ac-cordingly, a property known as SE(3)-equivariance. Under SE(3)-equivariance, any 3D rotation or translation of the in-put point cloud results in the same transformation in the output. This property is crucial in dynamic scenarios like robot grasping, autonomous driving, and augmented reality, where object pose is constantly changing. However, most existing methods fail to leverage this property, limiting their pose prediction performance. To address the issues mentioned above, in this paper, we propose an object pose estimation method called SEGPose, which integrates the geometric features, topological fea-tures, and SE(3)-equivariance properties of point clouds. To the best of our knowledge, this is the first time that geo-metric information, topological information, and SE(3)-equivariance of point clouds are simultaneously incor-porated into category-level object pose estimation. First, to enable geometric and topological features to effectively guide pose estimation, we design a geometry-topology-guided point cloud feature extraction and reconstruction method. This method guides the construction of topolog-ical features using both the topological information of the point cloud and the category-level topological information. By combining these with the geometric features of the point cloud, we make full use of the object’s structural informa-tion to enhance pose estimation. Then, we propose a pose estimation method based on SE(3)-equivariance features and design an SE(3)-equivariance-guided pose estimation head. This estimation head leverages SE(3)-equivariance features to guide the point cloud features of the object in predicting its pose. As a result, the predicted pose adapts dynamically to changes in the input, leading to improved accuracy and robustness in pose estimation. Finally, we ap-ply SEGPose to multiple datasets for performance evalua-tion. Experimental results show that SEGPose outperforms all existing depth-based category-level object pose estima-tion methods, and surpasses most state-of-the-art RGB-D-based category-level pose estimation approaches as well. In summary, the main contributions of this paper are summarized as follows: • We propose a point cloud feature extraction method that combines topological constraints, category-level topolog-ical constraints, and geometric constraints, and develop a geometry-topology-based 3D reconstruction method. • We propose an SE(3)-equivariant pose estimation method that guides the network to apply synchronized transfor-mations according to the point cloud’s SE(3)-equivariant properties, enhancing accuracy by ensuring consistency between point cloud transformations and predicted poses. • Our SEGPose outperforms existing depth-based pose es-timation methods on multiple public datasets and sur-passes most RGB-D-based methods, achieving state-of-the-art performance. 

## 2. Related Works 

2.1. Instance-level 6D Object Pose Estimation 

Instance-level 6D object pose estimation methods can be categorized into template matching, regression-based, and correspondence-based approaches. Template matching methods, such as [16, 27, 30], align 3D models to RGB-D images based on extracted features, which can be time-consuming. To address this, regression-based methods, like [17, 39], directly output the 6D pose from RGB images, though with lower accuracy. Correspondence-based meth-ods, such as [7, 15, 22, 28–30], establish 2D-3D or 3D-3D correspondences, using PnP and SVD to compute the 6D pose, with some relying on RANSAC-based PnP [2, 6]. All these methods are fully-supervised and require 3D CAD models. 

2.2. Category-level 6D Object Pose Estimation 

Instance-level 6D object pose estimation has made great progress but relies on 3D CAD models, limiting its ability to handle unseen objects. In contrast, category-level meth-ods aim to predict the pose of unseen objects in the same category. To enhance pose estimation accuracy, some methods in-corporate prior point clouds. In [32], Tian et al. im-prove accuracy by introducing prior point clouds. SGPA [5] uses a vision transformer to fuse features from the prior point cloud, scene point cloud, and RGB image. Cat-Former [41] enhances pose prediction by optimizing prior point clouds through deformation. Recent research also ex-plores prior-free methods. DualPoseNet [20] uses a dual-channel structure for feature extraction and a novel pose refinement method based on pose consistency. FS-Net [8] represents rotation with decoupled vectors, while VI-Net [21] separates rotation into viewpoint and in-plane rotations for higher precision. IST-Net [24] achieves state-of-the-art performance on the REAL275 benchmark by transforming camera-space features to world-space counterparts without priors. Although effective, these methods rely on RGB image data for pose estimation. To address this, several depth-based approaches have been proposed, such as [10, 19, 43, 44, 46]. Lin et al. introduced SAR-Net [19], which uses point clouds and shape registration for pose estimation. Di et al. proposed GPV-Pose [10], a geometry-guided frame-work with confidence-aware pose and bounding box predic-tions. While these methods excel in pose estimation, they mainly focus on geometric information, neglecting topolog-ical information and SE(3)-equivariance.

3.1. Pipeline Overview 

The SEGPose training pipeline is shown in Figure 2. We in-put the RGB and depth images to an instance segmentation network (e.g., Mask-RCNN [14]) to extract the object mask. The depth images are then cropped based on the instance mask to obtain the target object’s point cloud, denoted as 

Po ∈ RNo×3, with No points. SEGPose uses the HS-encoder [46] to extract geometric features and predict topo-logical features with guidance from point cloud topological labels. Using these features, it performs 3D reconstruction of the point cloud. Additionally, an SE(3)-equivariance en-coding module extracts SE(3)-equivariance features, which guide the pose prediction head for object pose estimation. Finally, the reconstructed point cloud and predicted pose are refined by aligning with the ground truth NOCS point cloud. 

3.2. Topological Label for Pose Estimation 

Geometric features can be constrained using the object model or NOCS point cloud. However, there is no suitable label for applying constraints to topological information. Therefore, we first construct topological labels to guide and constrain the topological features learned during training. In this paper, we use the persistent homology algorithm [13] to extract topological features, represented by persis-tence diagrams [11]. However, these diagrams consist of discontinuous birth-death points, making integration with neural network training challenging. To address this, we improve persistence diagrams using persistence images [1]. The calculation steps are as follows: First, we use the alpha complex method [12] to construct 1D and 2D topo-logical features of the point cloud, obtaining the birth-death coordinates of the persistence diagrams, D1 and D2. Then, we apply a linear transformation T (x, y ) = ( x, y − x) to obtain the birth-persistence coordinates. However, directly predicting the topological feature map may lead to model collapse. To address this, we use the method from [1] and apply a regularized Gaussian kernel to 

T (D), transforming discrete points into a continuous distri-bution. The regularized distribution is given by

3.3. Geometric and Topological Features Extraction 

After constructing the object’s topological labels, we build a network for predicting geometric and topological features to extract the geometric and topological information of the object. The geometric and topological feature extraction module of SEGPose is shown in Figure 2. We take the object point cloud Po as the input, and use the HS-encoder [46] to extract features from the object, ob-taining the object point cloud feature F . Then, we need to use the point cloud features F extracted by the network to predict the object’s topological information, and rely on the guidance of the topological information to complete the 3D reconstruction of the target object. We use the transformer-based graph module proposed in [41], which can effectively analyze the topological infor-mation between points in the point cloud. By constructing multiple topological graphs, it enables the extraction and analysis of topological features Ftopo of the points in the point cloud. Next, we use the extracted point cloud topological fea-tures Ftopo , combined with adaptive max pooling and MLP, to predict the point cloud topological graph. A topological information guidance head is then constructed to predict 1D and 2D persistence images using Ftopo . To align the persis-tence image with the actual topological structure and mini-mize deviations, we impose topological constraints. These constraints consist of two parts: First, the predicted topolog-ical features should roughly align with the actual object’s topological graph, as described in Section 3.2. However, due to noise, limited viewpoints, and other factors, the ac-tual topological labels may be imprecise. To address this, we introduce a category topological constraint. Objects within the same category share similar shapes and, conse-quently, topological structures. This constraint ensures that the predicted topological persistence image aligns with the object’s category-specific structure. By applying both the point cloud and category topological constraints, the pre-dicted persistence image converges to an appropriate solu-tion, aligning with both the point cloud’s topological struc-ture and the category’s topological characteristics. Then, we use the object’s 1D topological persistence im-age I1 and 2D persistence image I2 to generate its topolog-ical features Ft1 and Ft2, completing the 3D reconstruction of the point cloud Precon . Unlike previous methods, we in-corporate both geometric and topological features simulta-neously. This approach ensures that the reconstructed point cloud is not only geometrically accurate but also aligns with the actual topological structure. With dual constraints of ge-ometry and topology, the reconstruction reaches its optimal state. The reconstructor, consisting of multiple MLP lay-ers, integrates features to directly predict the reconstructed point cloud. 

3.4. SE(3)-Equivariance for Pose Estimation 

To fully leverage the SE(3)-equivariance feature of objects, we propose a pose estimation method guided by SE(3)-equivariance. Since SE(3)-equivariance differs from geo-metric features, we use Vector Neuron Networks (VNNs) [9] as the backbone to extract these equivariance features. We input the object point cloud Po and apply the VNN-DGCNN [9] layer for SE(3)-equivariance feature extrac-tion. VNN uses vector representations to capture spatial in-formation, making it ideal for tasks requiring equivariance to 3D transformations. Combined with DGCNN [36], VNN effectively extracts graph features from the point cloud. Fi-nally, we concatenate the outputs of each VNN layer to ob-tain the fused SE(3)-equivariance feature Ff use .Based on the fused SE(3)-equivariance features, we first apply the VNN-Linear layer to adjust the features, yielding the adjusted feature Fadj . We then compute the element-wise product of Fadj and Ff use to obtain the SE(3)-equivariance feature Fse . To adjust the point cloud shape, we use Ff use with an MLP to predict shape weights, and adjust the point cloud accordingly to obtain Padj . This adjusted point cloud is also considered part of the SE(3)-equivariance features. Finally, we concatenate Padj and 

Fse , apply an MLP, and obtain the final SE(3)-equivariance feature FSE .Finally, we hope to use SE(3)-equivariance features to effectively guide the object’s pose estimation. We pro-pose an object pose estimation head guided by SE(3)-equivariance features. In this head, SE(3)-equivariance fea-tures guide point cloud features to predict object pose pa-rameters. First, we adjust the point cloud feature F using 1D convolution and the SE(3)-equivariance features using VNN-Linear. These are concatenated to form the fused fea-ture Fse 1, which serves as input for the next layer’s SE(3)-equivariance features. Based on Fse 1, we generate feature 35117 weights W1 via a Sigmoid function to adjust the point cloud features, producing the adjusted feature V1. Finally, we use the output Vf inal to predict the rotational components Rr ,

Rb, the translational component t, and the scale factor s

through MLP. The object rotation R is computed from Rr

and Rb as in [10, 44, 46].

4.2. Experiments on CAMERA25 Dataset and REAL275 Dataset 

To compare SEGPose with SOTA methods, we conduct ex-periments on benchmark datasets, evaluating performance on the CAMERA25 and REAL275 datasets. The results are shown in Table 1, which presents the performance of both RGB-D-based and depth-based pose estimation methods. First, we compare SEGPose with depth-based meth-ods. Experimental results show that SEGPose outperforms previous approaches, with improvements stemming from three key aspects: (1) SEGPose incorporates both geomet-ric and topological features during point cloud reconstruc-tion, ensuring optimal quality and accurate shape and struc-tural information for pose estimation. (2) SEGPose in-troduces SE(3)-equivariance and designs a pose estimation head based on this property, enhancing pose prediction ac-curacy under varying viewpoints. (3) Data augmentation techniques, such as scale changes, random cropping, and point cloud dropout, are applied during training, improving network robustness and pose estimation performance. In contrast, previous methods focus mainly on geo-metric features, neglecting topological features and SE(3)-equivariance. Some approaches, like SAR-Net, rely on prior point clouds that require deformation; ineffective de-formation can degrade pose estimation. Compared to the SOTA method HRC-Pose, SEGPose achieves a better per-formance on most metrics, delivering excellent pose esti-mation results. We compare SEGPose’s performance with other RGB-D-based methods. As shown in Table 1, SEGPose outper-forms most methods but still lags behind the SOTA method, SpotPose. This gap is primarily due to SpotPose’s use of RGB-D information for more accurate point cloud re-construction and keypoint prediction. However, SEGPose achieves significantly higher prediction speeds, making it better suited for real-time object pose estimation in practi-cal scenarios. Finally, we also provide the pose visualization results of SEGPose. We compare SEGPose with the previous depth-based SOTA method, HS-Pose, and the experimental results are shown in Figure 3. Experimental results show that SEGPose outperforms HS-Pose in capturing poses of complex object categories, such as cameras and mugs. This is due to SEGPose’s ef-fective use of point cloud topology and SE(3)-equivariance, which enhance the network’s ability to grasp the scale and shape of the point cloud, improving pose accuracy.

## 5. Conclusion 

In this paper, we propose a new depth-based category-level object pose estimation method, SEGPose. First, we introduce a point cloud reconstruction method guided by geometric and topological information, achieving precise reconstruction of object point clouds. Then, we present a pose estimation method based on SE(3)-equivariance, which uses SE(3)-equivariance to guide the network for ac-curate object pose prediction. Finally, we conduct perfor-mance tests on various datasets and robotic grasp tasks, and the experimental results show that SEGPose outperforms all existing depth-based category-level object pose estimation methods, achieving state-of-the-art performance. 35121 Acknowledgments: The work was supported by the Na-tional Natural Science Foundation of China under Grant 62173035, Grant 61803033 and Grant 61836001.
